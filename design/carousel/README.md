# 六格旋转笔筒 v10

用途：桌面近距离收纳与夹画，手拨旋转；先取顶环，再向上抽换亚克力。
形态：白色、通透、整齐；六棱柱与削角六边形旋转筒底上下对齐，落在居中的外购旋转器与静止圆底座上。六面等价，整体无尺寸或版本文字。隔板高164mm，与顶环顶面齐平。
材料：主体白色PLA、透明PMMA、纸卡、背胶硅胶垫；旋转器按用户指定为透明亚克力，实物型号及内部机构尚未核实。接口 panel_slots / rotation / top_ring / center_alignment；参考 reference_image / user_turntable_dimensions。

## Making and assembly
打印件三个：旋转筒身、静止底座、可拆顶环。旋转器上下盘均为参考外形，不是打印件；两层表示同一个外购总成，采购数量为1。
白色PLA，0.4mm喷嘴、0.2mm层高、至少4圈壁。底座与筒底平面朝下；顶环上表面朝床、裙边向上。可用打印空间240×240×180mm，转体单件高170mm。保持名义槽宽3.5mm，先校准打印公差，不改变用户指定尺寸。5mm盲槽顶有小跨度桥接，清理毛刺即可。
十二张透明PMMA板97.26×159.60×1.50mm，建议切割公差±0.10mm并去毛刺。双板夹0.2mm纸卡，叠厚3.2mm；槽宽3.5mm、槽深2.5mm，板端留0.2mm、实际咬入2.3mm。纸卡92×154mm，彩色矢量面仅示意印刷图案，不应3D打印。
底座上表面中心和筒底下表面中心均有直径5mm、深2mm圆形浅槽。两盘厚度均为6mm，槽后剩余4mm。浅槽用于胶接对位，不是贯穿孔或旧导向柱配合孔。
将用户选定旋转器的下表面粘接到底座上表面，再将上表面粘接到筒底下表面，按旋转器圆心与浅槽圆心对齐。胶只作用于指定上下粘接面，避开旋转层缝隙。具体胶种、表面处理、固化与承重按实物材质和产品说明执行；目前无旋转器产品图；采购候选胶为3M 9472LE，胶厚每面约0.132mm，PLA及旋转器材质的实际粘接仍需小样验证。
模型采用外径120mm、总高11mm；下盘底面z=6mm，上盘顶面z=17mm，筒底下表面z=17mm。模型胶层名义厚度为0，实物高度会增加实际胶层厚度。透明亚克力上下两层各5.5mm，按用户指定平分；为不增加总高，两个包络层相接，不额外加入缝高；内部轴承、铆接和孔位未建模。外购总成的内部工作与额定载荷未由CAD验证。
底座下六片直径14mm、含胶总厚1.5mm背胶硅胶垫，嵌入0.5mm深浅窝、外露1mm。胶接后不能像原滑动支承版本那样直接提离筒身拆洗。
六个隔板端头中间填平，左右两槽保留。每面依次插入内亚克力、纸卡、外亚克力，最后放上顶环。顶环导向净宽3.6mm，板叠层每侧0.2mm余量；下方十二条固定边长92.0551mm，两端距隔板各0.3mm。外端台阶承托顶环，隔板与顶环内侧法向间隙0.25mm。顶环六处削平面按实际隔板端头匹配，径向偏置109mm、宽5.669106mm，六处均验证平面位置和宽度一致。顶环竖向小圆角0.6mm、上缘倒角0.5mm，内孔和下方夹板导向不变。顶环和隔板顶面同为z=187mm，含脚垫整机高188mm（未计胶层）。换画先上提顶环至少3mm后取开，再抽板。
目标负载1.5kg仅供样机验证，需实物检查胶接强度、转盘额定载荷、侧板挠度和满载稳定性。

## Version

## Geometry validation
底座和筒底均为单一实体。用实际几何布尔提取浅槽，测得两处均为5×5×2mm，空腔体积39.269908mm³。旋转器外形直径120mm、总高11mm，整机29个实体装配以当前检查结果为准；旋转器直径120mm、高11mm。六处顶环与端头平面位置及宽度误差小于1e-6mm。转体与上盘相对底座、下盘转动360°无外部干涉，网格公差0.02mm、步距1mm；不代表外购转盘内部机构或承载认证。彩色整机预览隐藏外层亚克力便于看卡片，完整灰模用于装配检查。
