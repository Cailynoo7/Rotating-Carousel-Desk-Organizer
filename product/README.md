# 走马灯式旋转收纳笔筒 v10

六棱柱主体以中心到六个顶点的径向隔板分成六格，白色主体配六面透明双层亚克力夹画。采用用户参考图比例，不在外观标尺寸或版本号。纯机械手拨旋转，不需要电路、电机或程序。

## 必须满足
筒身底板采用与筒身、顶环对齐的削角六边形，名义未削角对角跨度220 mm、底厚6 mm；静止底座保持直径230 mm圆形。六面各夹两张1.5 mm亚克力，插槽宽3.5 mm、深2.5 mm；径向隔板至少6 mm，端部两槽之间填实填平，不留第三条凹槽。独立可拆六边形顶环固定板顶，换画先取环再抽板。隔板顶部与顶环顶部齐平，环下固定边左右延长到接近隔板，顶环六个棱角削平，与下方隔板端头的平面上下对齐。
旋转采用用户选定的双层圆盘，准确外径120 mm、整高11 mm，上下透明亚克力两层各5.5 mm，上下两面分别粘接筒底与底座。删除原滑环、导向柱及同心环槽。底座上表面与六边形筒底下表面圆心各有直径5 mm、深2 mm的圆形浅槽，作为粘接对位标记。旋转器见零件表 turntable 行。

## 版本规则
当前产品版本为v10，每次完成产品更新同步递增整数版本号。版本只记录在资料中，不印在模型表面。

## 默认实现
侧板槽段标称高160 mm，隔板总高164 mm。隔板与顶环内侧法向间隙0.25 mm；顶环下固定边两端各留0.3 mm间隙，总长约92.06 mm。主体采用白色PLA，底座保留防滑脚垫。
旋转器按用户指定建立透明亚克力双层外形，直径120 mm、整高11 mm、每层5.5 mm；两层相接以表达总包络，不另加高度。暂未收到实物产品图，内部旋转机构、紧固件和孔位未建模。名义装配未计入胶层厚度，实物总高随胶层增加。粘接完成后筒身不再直接提离底座，换卡仍从顶部进行。
目标收纳负载1.5 kg仅为样机目标，需实物确认旋转器承重、侧板挠度及胶接强度。打印件需240×240×180 mm可用打印空间，不拆分圆盘。卡片为名义0.2 mm纸卡，图案从用户样图选取金发、蓝发、粉发、紫色星空、绿色花朵、橙色运动六款。横向4:3白底产品展示图基于当前模型生成，不印文字或尺寸，旋转器按11mm总高及筒底遮挡关系表现。

## 验收
六格上口贯通，顶环独立拆装；顶环六处削平面与隔板端头对齐；两面对位浅槽均为直径5 mm、深2 mm；旋转器名义包络为直径120 mm、高11 mm；外部转动避让不撞底座。旋转器内部运行、底面平整度和胶接强度由实物试装确认。不存在电气接线。
